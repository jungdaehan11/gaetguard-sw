# 갯가드 빛길 안내 SW (드론 시연용)

7팀 "갯가드" — 밤·새벽 밀물에 퇴로가 끊기는 갯벌 고립을 막기 위한 아이디어 중 **드론 빛길 안내** 부분의 시연용 코드입니다.
드론이 사람 앞에서 날며 LED 빛 자국을 길 위에 찍어 길을 안내합니다. ArduPilot(ArduCopter) 기체를 MAVLink(pymavlink)로 움직입니다.

> **지금은 시뮬레이터 전용입니다.** 사람 위치는 컴퓨터 안의 "가상의 사람"이고, 실기체 비행은 코드에서 막아 두었습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `gg_lead_v4.py` | **최신.** 빛 자국을 사람 3m 앞 길 위에 찍기, 모퉁이에서 멈춤 → 드론이 돎 → 새 방향 안내 |
| `gg_plot_v4.py` | v4 비행 기록(CSV) → 결과 그림(PNG) |
| `old/gg_lead_v3.py`, `old/gg_plot_v3.py` | v3: 빛 신호 3가지(켜짐·깜빡임·좌우 쓸기) |
| `old/gg_sitl_lead.py` | v2: 직선 길, 사람 7m 앞 유지 |
| `docs/` | 시뮬레이터 결과 그림 (ArduCopter 3.6.12 SITL) |

## 빛 신호 (v4, 2026-11-04 팀 결정)

| 신호 | 뜻 | 언제 |
|---|---|---|
| 켜짐 | 따라오세요 | 기본. 빛 자국이 사람 3m 앞 길 위를 같이 감 |
| 깜빡임 | 빛 자국까지 와서 멈추세요 | ① 빛 자국이 모퉁이에 닿았을 때 ② 사람이 길에서 2m 넘게 벗어났을 때 |

모퉁이: 빛 자국이 모퉁이에 닿으면 고정 + 깜빡임 → 사람이 모퉁이에 와서 멈춤 → 드론이 모퉁이를 원호로 돌아 빛 자국을 꺾인 길 3m 지점으로 → 다시 켜짐.

LED는 수직에서 앞으로 35° 기울여 고정했다고 가정합니다 [가정]. 고도 7m에서 빛 자국은 드론 앞 약 4.9m (7 × tan35°). 드론은 빛 자국에서 진행 방향으로 4.9m 앞에 떠서 사람 쪽을 바라봅니다.

## 실행 (Windows + Mission Planner 시뮬레이터)

```
python -m pip install -r requirements.txt
```

1. Mission Planner → SIMULATION → Multirotor, 연결될 때까지 기다림
2. 이 폴더에서 cmd 열기
3. `python gg_lead_v4.py` (5762가 안 되면 `python gg_lead_v4.py tcp:127.0.0.1:5763`)
4. "시동 꺼짐 → 프로그램 끝"과 요약이 나올 때까지 창을 닫지 않기 (중간에 멈추려면 Ctrl+C → 그 자리 정지)
5. `python gg_plot_v4.py gg_log_YYYYmmdd_HHMMSS.csv` → 같은 이름의 PNG

땅에서 빛(릴레이)만 시험: `python gg_lead_v4.py COM5 --light-test` (시동 안 걺, 배터리·프로펠러 없이 USB만, AUX 단자에 연결된 장치 먼저 확인)

## 안전장치

- 지상국 번호 255로 하트비트를 1초마다 보냄 → 프로그램이 죽으면 기체가 "지상국 끊김"으로 귀환(FS_GCS_ENABLE=1일 때)
- 시동이 꺼질 때까지 하트비트 유지 (먼저 끄면 착륙 중 귀환할 수 있음)
- 조종자가 모드 스위치를 돌리면(GUIDED가 아니게 되면) 바로 명령을 멈춤
- Ctrl+C → BRAKE (그 자리 정지)
- 소프트웨어 울타리 60m, 실기체 연결(COM 등)이면 비행 막음 → `--real`과 확인 입력이 있어야 날 수 있음
- **GUIDED 비행 중 안전 조종자는 스로틀 스틱을 가운데에 둘 것** (아래에 둔 채 LOITER로 넘겨받으면 바로 내려옴)

## 시뮬레이터 결과 (v4, ArduCopter 3.6.12 SITL, 실기체 설정값 일부 적용)

- 꺾인 길 55m(북 25 → 동 15 → 북 15), 137초
- 빛 자국이 길에서 벗어난 거리(따라가는 동안): 중앙값 0.00m, 95% 0.23m, 최대 0.81m (모퉁이 돈 직후 약 2초)
- 모퉁이마다 사람이 서서 기다린 시간 약 7.8초, 도는 동안 사람-드론 최소 5.1m
- 길 이탈 2.0m → 깜빡임 → 약 4초 만에 돌아옴
- 실제 바람·GPS 오차·LED 밝기는 아직 시험 안 함

## 아직 정하지 않은 것 / 가정

- 실제 시연에서 사람 위치를 어떻게 알지 (지금은 가상의 사람)
- 걸음 속도 0.5m/s, 안전한 길 폭 ±2m, LED 35° [확인 필요]
- 모퉁이 바깥쪽에 약 5m 빈 공간 필요
- 실기체 비행 전: 관리자 허락, 안전 설정 수정(배터리 부족 동작·귀환 높이·울타리 등), 조종자 증명 [법규 확인: 항공안전법 제125조], 비행 구역 확인 [법규 확인: 항공안전법 제127조]
