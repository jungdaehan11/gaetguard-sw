# 갯가드 빛길 안내 SW (드론 시연용)

7팀 "갯가드" — 밤·새벽 밀물에 퇴로가 끊기는 갯벌 고립을 막기 위한 아이디어 중 **드론 빛길 안내** 부분의 시연용 코드입니다.
드론이 사람 앞에서 날며 LED 빛 자국을 길 위에 찍어 길을 안내합니다. ArduPilot(ArduCopter) 기체를 MAVLink(pymavlink)로 움직입니다.

> **지금은 시뮬레이터 전용입니다.** 사람 위치는 컴퓨터 안의 "가상의 사람"이고, 실기체 비행은 코드에서 막아 두었습니다.

## 조위·지형 자료 (2026-11-05)

- **대상 지역: 영흥도** (팀 결정). 실제 사고 현장(내리 갯벌, 2025-09-11), 해경 영흥 파출소 드론 배치, 섬 안 조위관측소 DT_0043
  - 약점: 내리 갯벌(꽃섬 인근~하늘고래전망대)은 2026-01-12부터 야간·기상특보 때 출입통제구역 (인천해양경찰서, 경향신문 2026-05-04) → "해경이 단속·구조에 쓰는 도구"로 설명
- 순서
  1. `gg_station_fetch.py --stations DT_0043 --start ... --min 1` → 관측소 실측·예측 (API는 2025-01-01부터)
  2. `gg_tide_correction_test.py tide\station_DT_0043_1m.csv` → 보정 방법 비교
  3. `gg_badanuri_parse.py` → 바다누리 1분 자료(2021~2024, zip 그대로) 정리 CSV, `gg_tide_harmonic.py` → 조석 성분 뽑아 우리 예측
  4. `terrain\gg_terrain_area.py youngheung` → 수심·갯골·해안선 자르기와 지도
  5. `gg_retreat_map.py --tide tide\station_DT_0043_1m.csv --start ... --end ...` → **퇴로 마감 지도** (칸마다 마지막 출발 시각, 가장 오래 열린 길)
- 보정 시험 1차 결과 (인천송도 2026년 3월 1분): 지금 계획의 **높이 보정**이 가장 좋음. 물 찰 때 시각 오차 95%가 예측만 27분 → 1시간 뒤 보정 10분. 시각 보정은 더 나쁨
- 보정 시험 2차 (영흥도 2024년 1분, 예측은 2021~2023으로 뽑은 우리 조석 성분): 높이 보정이 또 가장 좋음. 물 찰 때 시각 오차 99%가 예측만 34분 → 30분 앞 14분 / 1시간 앞 20분 / 2시간 앞 29분. 여름이 가장 나쁨(1시간 앞 25분)
- 자료 문제: 1분 실측에 빈 값이 0.0으로 적힌 곳이 있음 (3월 31곳) → 스크립트·커넥터에서 걸러냄
- 조위 API는 `tide_mcp/` 커넥터로 Claude가 직접 부름

## 빛 신호 (2026-11-04 팀 결정)

| 신호 | 뜻 | 언제 |
|---|---|---|
| 켜짐 | 따라오세요 | 기본. 빛 자국이 사람 3m 앞 길 위를 같이 감 |
| 깜빡임 | 빛 자국까지 와서 멈추세요 | ① 빛 자국이 모퉁이에 닿았을 때 ② 사람이 길에서 2m 넘게 벗어났을 때 |

모퉁이: 빛 자국이 모퉁이에 닿으면 고정 + 깜빡임 → 사람이 모퉁이에 와서 멈춤(1초 확인) → 켜짐, 빛 자국이 꺾인 길 위로 앞서감 → 사람이 방향을 틀어 따라옴.

## 드론 위치 정하는 법 (v4.1)

LED는 수직에서 앞으로 35° 기울여 고정했다고 가정합니다 [가정]. 그러면 빛 자국은 늘 **드론 바로 아래에서 4.9m** (7m × tan35°) 떨어진 곳에 떨어집니다.
그래서 드론은 **빛 자국에서 직선거리 4.9m인 곳**에 떠서 빛 자국을 바라봅니다.

- 곧은 길: 빛 자국에서 길을 따라 4.9m 앞 (길 위)
- 빛 자국이 모퉁이 4.9m 안에 들어오면: 빛 자국 둘레 4.9m 원 위에서 새 길 쪽으로 고르게 돌림 → 빛 자국이 모퉁이에 닿을 때 드론은 꺾인 새 길 4.9m 지점
  - 기수 회전은 초당 약 9° (실기체 제한 ATC_SLEW_YAW 초당 20°보다 느림)
  - 대신 드론이 모퉁이에서 길 바깥으로 최대 약 1m 살짝 둥글게 돎
- 드론이 목표보다 많이 늦으면(모퉁이에서 다시 출발할 때 등) 지금 자리에서 빛 자국이 실제로 떨어질 길 위 점을 바라봄 → 빛 자국이 길 밖으로 안 나감

## 실행 (Windows + Mission Planner 시뮬레이터)

```
python -m pip install -r requirements.txt
```

1. Mission Planner → SIMULATION → Multirotor, 연결될 때까지 기다림
2. 이 폴더에서 cmd 열기
3. `python gg_lead_v4.py` (5762가 안 되면 `python gg_lead_v4.py tcp:127.0.0.1:5763`)
4. "시동 꺼짐 → 프로그램 끝"과 요약이 나올 때까지 창을 닫지 않기 (중간에 멈추려면 Ctrl+C → 그 자리 정지)
5. `python gg_plot_v4.py gg_log_YYYYmmdd_HHMMSS.csv` → 같은 이름의 PNG (v3 기록은 `old/gg_plot_v3.py`)

땅에서 빛(릴레이)만 시험: `python gg_lead_v4.py COM5 --light-test` (시동 안 걺, 배터리·프로펠러 없이 USB만, AUX 단자에 연결된 장치 먼저 확인)

## 안전장치

- 지상국 번호 255로 하트비트를 1초마다 보냄 → 프로그램이 죽으면 기체가 "지상국 끊김"으로 귀환(FS_GCS_ENABLE=1일 때)
- 시동이 꺼질 때까지 하트비트 유지 (먼저 끄면 착륙 중 귀환할 수 있음)
- 조종자가 모드 스위치를 돌리면(GUIDED가 아니게 되면) 바로 명령을 멈춤
- Ctrl+C → BRAKE (그 자리 정지)
- 소프트웨어 울타리 60m, 실기체 연결(COM 등)이면 비행 막음 → `--real`과 확인 입력이 있어야 날 수 있음
- **GUIDED 비행 중 안전 조종자는 스로틀 스틱을 가운데에 둘 것** (아래에 둔 채 LOITER로 넘겨받으면 바로 내려옴)

| 모퉁이에서 사람이 서 있던 시간 | 약 1.3초 (+ 다시 걷기까지 반응 1초 가정) | 같음 |
| 사람-드론 최소 거리 | 4.8m (모퉁이에서 기다릴 때) | 4.9m |
| 길 이탈 2m → 깜빡임 → 돌아옴 | 약 4초 | 약 4초 |

- 모퉁이에서 다시 출발하는 순간 약 0.5초 동안 빛 자국이 사람 발밑 근처(앞뒤 0.7m 안)에 있음
- 실제 바람·GPS 오차·LED 밝기는 아직 시험 안 함

## 아직 정하지 않은 것 / 가정

- 실제 시연에서 사람 위치를 어떻게 알지 (지금은 가상의 사람)
- 걸음 속도 0.5m/s, 안전한 길 폭 ±2m, 반응 시간 1초, LED 35° [확인 필요]
- 실기체 비행 전: 관리자 허락, 안전 설정 수정(배터리 부족 동작·귀환 높이·울타리 등), 조종자 증명 [법규 확인: 항공안전법 제125조], 비행 구역 확인 [법규 확인: 항공안전법 제127조]
